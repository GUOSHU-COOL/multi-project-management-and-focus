# 多项目管理以及注意力集中｜应用手册

## 1. 适合谁

它帮助你同时管理多个任务，知道每个任务当前推进到哪里、今天应该推进多少，并据此合理分配时间与注意力。

## 2. 基本工作流

1. 在“项目”中新建项目，填写名称、说明和图标。
2. 在计划区搭建任务树：阶段可以包含子任务，任务可无限嵌套。
3. 把今天要做的计划任务拖到“今天”；长期任务和临时任务也会进入同一个今日列表。
4. 在今日列表中排序、编辑、完成或拖到移除区。移除只影响今天，不会删除项目计划。
5. 用思维导图查看结构、调整父子关系、手动摆放节点或添加关联线。
6. 在四象限中判断优先级，需要集中时启动专注计时。

## 3. AI 与数据安全

AI 不会直接修改存档。它只能返回 `AIProposal` / `TaskOperation`，应用会先校验 UUID、项目归属、任务树循环和操作范围，再展示预览；只有用户确认后才执行。API Key 只保存在 macOS 钥匙串。

## 4. 数据位置与备份

工作区文件位于 `~/Library/Application Support/CloudPlan/workspace.json`。应用每次变更后原子写入。备份时复制该文件即可；不要把包含个人记录的文件提交到公开仓库。

## 5. 开发与验证

```bash
swift test
./scripts/build-app.sh
```

发布前应检查 1240×780 与最小 760×560 窗口尺寸，并确认新增 AI 写操作拥有对应的操作类型、校验、预览文案和测试。
