# 多项目管理以及注意力集中

一款轻量、安静的原生 macOS 应用：先看清多个项目的全貌，再把今天真正能做的一小步放到眼前。项目任务、长期任务和临时任务进入“今天”后使用同一个列表，并可配合四象限与专注计时，减少切换，保持方向。

English: [Multi-Project Management & Focus](docs/USER_GUIDE.en.md)

## 已有能力

- 海蓝、天蓝与奶白云朵的原生 SwiftUI 界面
- 宽窗口左右分栏、窄窗口上下分栏
- 项目与计划任务创建、编辑、删除
- 清晰的新建项目窗口，可填写说明、选择图标；项目支持改名和安全删除
- 计划任务拖入今天，今日任务拖动排序、完成与编辑
- 项目任务可无限层级嵌套；列表拖放可调整父子关系
- 思维导图与树形列表双视图，支持整棵分支自由拖动、网格/节点对齐、跨分支重挂和一键整理
- 思维导图里可以在任意两个任务之间画自由连接线（天蓝虚线）；点击连线即可断开，连接线只表达关联，不改变任务层级
- 今日任务拖到列表下方的移除区，松手即从今天移除
- 统一的项目与任务编辑器，提供图标选择、清晰输入面和紧凑时长控制
- 跨项目四象限：任务引用拖放、象限间移动与同象限排序
- 象限任务一键开始专注，可选预设或自定义时长，并显示全局倒计时、暂停与结束状态
- 长期任务进入今日清单
- 本地 JSON 自动保存
- AI 整理入口：结构化变更、校验、预览、确认后执行
- AI 可一次构建多层任务树、重组已有层级并从树中挑选今日任务
- AI 可根据提示词创建完整项目、调整任务象限，并限制只发送当前项目
- 支持 OpenAI Responses API 与 HTTPS 自定义兼容服务，可配置模型、推理强度和服务等级
- API Key 按服务地址分别保存在 macOS 钥匙串；默认发送 `store: false`
- 支持选择多个 Notion CSV/Markdown 导出文件，由 AI 转换为可确认的项目与任务操作

## 使用

双击 `Build/云上计划.app`。如需重新生成应用，运行 `scripts/build-app.sh`。

AI 功能需要用户自己的 API Key；不填写时，其余功能完全离线可用。自定义服务必须兼容 Responses API。

从 Notion 导入时，先在 Notion 中导出 Markdown/CSV 并解压，然后在“AI 整理”中选择一个或多个导出文件。文件先在本机读取，点击“生成导入预览”后才会连同所选任务范围发送给当前 AI 服务；确认预览前不会修改工作区。
